# 춘식이 공부게임 웹앱

## 기능
- 역사 / 국어 / 사회 / 영어
- 사진 촬영 및 이미지 선택
- Tesseract.js 기반 한국어+영어 OCR
- OCR 결과 확인 및 직접 수정
- 핵심 내용/포인트 화면
- 하/중/상 난이도
- 6문제 퀴즈
- XP를 브라우저 localStorage에 저장
- 모바일/아이패드 화면 대응
- PWA manifest 포함

## 실행
이 폴더의 `index.html`을 정적 웹호스팅에 올리면 된다.
OCR 라이브러리는 CDN에서 불러오므로 인터넷 연결이 필요하다.

## 주의
현재 버전의 문제 생성은 입력된 학습문장을 기반으로 하는 로컬 규칙형 프로토타입이다.
실제 AI 수준의 요약/문제 생성을 붙이려면 별도의 AI API 서버가 필요하다.
